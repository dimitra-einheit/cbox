# cbox

## dronemap: local drone survey toolkit

[`dronemap/`](dronemap/) plans Litchi mapping missions for the DJI Mavic 2 Pro and processes the photos with
OpenDroneMap (orthophoto, terrain and surface models, textured 3D model). It also trains Gaussian splats on
the Mac's GPU with OpenSplat and designs earthworks (cut/fill, ponds, drainage) from the terrain model.

Start with [dronemap/README.md](dronemap/README.md).
